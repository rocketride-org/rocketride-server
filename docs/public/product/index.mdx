# RocketRide <span className="rr-accent">Documentation</span>

RocketRide is an open source AI meta-harness with an enterprise-grade runtime built on C++, for companies and pro-builders building durable AI at production scale. Pipelines are portable JSON that run the same way on your laptop, your servers, or RocketRide Cloud.
