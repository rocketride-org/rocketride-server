## What it does

Gives agents the ability to run [Apify](https://apify.com) Actors (web scrapers and automation tasks) and read their results. Useful for agents that need to extract structured web data on demand.

## Tools

| Tool                      | Description                                      |
| ------------------------- | ------------------------------------------------ |
| `apify.run_actor`         | Run an Actor to completion and return its items  |
| `apify.get_dataset_items` | Read items from an existing dataset              |

### apify.run_actor

| Parameter   | Required | Description                                              |
| ----------- | -------- | ------------------------------------------------------- |
| `actor_id`  | yes      | Actor ID or name, e.g. `apify/website-content-crawler`  |
| `run_input` | no       | Input object passed to the Actor (Actor-specific)       |
| `limit`     | no       | Max items to return (default 100)                       |

Returns the resulting dataset id and its items.

### apify.get_dataset_items

| Parameter    | Required | Description                  |
| ------------ | -------- | ---------------------------- |
| `dataset_id` | yes      | Dataset to read              |
| `limit`      | no       | Max items to return (default 100) |

Returns the dataset items.

## Configuration

| Field                | Description                                                      |
| -------------------- | ---------------------------------------------------------------- |
| API Token            | Apify API token                                                  |
| Max Items            | Upper cap on items returned per call (agent requests are clamped) |
| Run Timeout (seconds)| Max seconds an Actor run may take before it is stopped           |
| Max Cost (USD)       | Spend limit per run for pay-per-event Actors                     |
