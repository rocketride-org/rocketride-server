## What it does

Parses documents using LandingAI's Agentic Document Extraction (ADE) cloud API,
extracting clean Markdown text and structured tables. Handles PDFs, images,
scanned documents, and office files (DOCX, PPTX, XLSX).

**Lanes:**

| Lane in | Lane out | Description                               |
| ------- | -------- | ----------------------------------------- |
| `tags`  | `text`   | Full document rendered as Markdown        |
| `tags`  | `table`  | Extracted tables in Markdown table format |

## Configuration

| Field   | Description                                                                                    |
| ------- | --------------------------------------------------------------------------------------------- |
| API Key | Your LandingAI ADE API key. Falls back to the `VISION_AGENT_API_KEY` env var when left blank. |
| Model   | The Agentic Document Extraction model used to parse documents (`dpt-2-latest`).                |
| Region  | `US (production)` or `EU (eu-west-1)` — pick the EU endpoint for eu-west-1 data residency.     |
