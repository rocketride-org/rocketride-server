## What it does

Connects RocketRide to [n8n](https://n8n.io) workflow automation. This is a dual node:

- As a pipeline step, lane input is posted to a workflow webhook and the response flows downstream.
- As an agent tool, an agent can trigger workflows and inspect workflows or executions at runtime.

n8n is self-hosted, so configure the instance base URL and, for public API operations, an API key.

## Pipeline step

The pipeline step sends accumulated lane input to the configured **Workflow (webhook path)**.

| Lane in | Lane out | Description |
| --- | --- | --- |
| `text` | `text`, `answers`, `table` | Sends text to the workflow and emits the result |
| `questions` | `answers`, `text`, `table` | Sends question text to the workflow and emits the result |
| `documents` | `documents`, `text`, `table` | Sends documents to the workflow and emits the result |
| `image`, `audio`, `video` | matching binary lane, `text`, `answers`, `table` | Sends binary input as multipart and can emit returned binary data |

Use `payloadMode: structured` when the workflow needs document boundaries, metadata, or separate text fields. Use `simple` for the back-compatible `{"data": text}` body.

## Agent tools

Tools are exposed under the `n8n` namespace.

| Tool | Description |
| --- | --- |
| `n8n.trigger_workflow` | Trigger a workflow by webhook path and return the response |
| `n8n.list_workflows` | List workflows with ids, active state, and webhook paths |
| `n8n.get_workflow` | Get one workflow by id |
| `n8n.list_executions` | List recent executions |
| `n8n.get_execution` | Get one execution with data |
| `n8n.activate_workflow` | Activate a workflow when read-only mode is off |
| `n8n.deactivate_workflow` | Deactivate a workflow when read-only mode is off |

The agent never chooses the n8n host. Every request targets the configured Base URL, and workflow arguments are sanitized to plain webhook paths.

## Configuration

| Field | Default | Description |
| --- | --- | --- |
| n8n Base URL | `http://localhost:5678` | n8n instance URL. In Docker, use `http://host.docker.internal:5678` or `http://n8n:5678`. |
| API Key | empty | n8n public API key (`X-N8N-API-KEY`). Required for listing, inspecting, and async polling. |
| Workflow | empty | Webhook path the target workflow listens on. Used by the pipeline step and as the default for `trigger_workflow`. |
| Payload shape | `simple` | `simple` sends `{"data": text}`; `structured` preserves text, documents, and metadata. |
| Result mode | `sync` | `sync` waits for the webhook response; `async` triggers then polls the execution via the public API. |
| Sync timeout | `30` | Max seconds to wait for the webhook response in sync mode (1-3600). |
| Async timeout | `120` | Max seconds to wait for an async execution before raising an error (5-3600). |
| Webhook auth | `none` | Auth on the workflow Webhook node: `none`, `header`, `basic`, `bearer`, or `jwt`. Separate from the API key. |
| Verify TLS certificate | `Yes` | Leave enabled unless using a self-signed local n8n over HTTPS. |
| Read-only mode | `Yes` | Blocks write operations such as activate and deactivate. |

## Environment variables

Set fields directly in the node config or provide these environment variables:

```bash
ROCKETRIDE_N8N_URL=http://localhost:5678
ROCKETRIDE_N8N_KEY=...
ROCKETRIDE_N8N_WORKFLOW=enrich-invoice
```

`ROCKETRIDE_N8N_WORKFLOW` is used when the node config workflow field is empty. Smoke tests require both `ROCKETRIDE_N8N_KEY` and `ROCKETRIDE_N8N_WORKFLOW`.

## n8n setup notes

- The target workflow needs a Webhook trigger node. Manual, cron, and event-triggered workflows need a webhook dispatcher wrapper.
- Production webhooks only exist after the workflow is activated or published in n8n.
- In sync mode, return data with a Respond to Webhook node or configure the Webhook node to respond when the last node finishes.
- If RocketRide runs in Docker, `localhost` points at the RocketRide container, not the host machine.
