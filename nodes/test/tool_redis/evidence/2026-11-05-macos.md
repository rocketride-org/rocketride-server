## Reproduction

Use the fixture and engine setup in [the test README](../README.md), then run
from `nodes/`:

```sh
../dist/server/engine -m pytest test/tool_redis test/memory_persistent test/test_contracts.py -q --rootdir .
../dist/server/engine -m pytest test/test_dynamic.py -k tool_redis -q --rootdir .
```

Set all three `REDIS_*_TEST_URL` variables, the test CA path and
`ROCKETRIDE_REDIS_HOST` as documented. Missing live fixture variables cause
skips and do not establish live verification. The generic Redis case now
selects fixture port 6381 explicitly in its test configuration. Previously
it ignored the unlisted `ROCKETRIDE_REDIS_PORT` variable and connected to
6379, which failed when using the supplied fixtures. A pipeline-builder
regression test covers the correction.
