RocketRide Chat Widget demo

One bundle, two consumption modes: place the <rocketride-chat> web component inline anywhere on the page, or add a single script tag with data-* attributes to get the floating launcher bubble — it is already active in the corner of this page.

Auth: the widget authenticates with the pipeline's public authorization key — the {public_auth} value from the chat node's published {host}/chat?auth={public_auth} link. Never use the engine API key or any private token in a web page. The values below are placeholders; paste your own public key.

1 — Inline web component

2 — Script-tag launcher bubble

The bubble in the corner of this page comes from the script tag at the bottom of this file — no other markup required. Its configuration (data-engine-url, data-auth, data-title, data-accent, data-position, data-welcome, data-placeholder, data-theme) is fixed at load time; edit the attributes in this file and reload to change it. Click the launcher to open the panel, press Escape to close it.
