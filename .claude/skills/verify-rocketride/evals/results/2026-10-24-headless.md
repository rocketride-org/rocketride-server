# Eval run, 2026-10-24: headless surfaces

Branch `feat/verify-rocketride-headless`, engine built from `ada02aec` (develop). 21 cases (5 planted bugs, 6 replayed real bugs, 10 clean controls) run once per variant: Claude Code (`sonnet`) and Codex (`gpt-6.1-sol`, medium effort), each with and without this skill. 84 runs. Scored by `score.py`; Claude Haiku judged matches, with one manual override recorded in that run's `judge.json`.

## Results

| Variant | Bugs caught | False alarms | Median minutes | Median tokens |
|---|---|---|---|---|
| Claude, with skill | 11 of 11 | 0 of 10 | 0.7 | 315,370 |
| Claude, no skill | 10 of 11 | 1 of 10 | 1.5 | 790,929 |
| Codex, with skill | 11 of 11 | 1 of 10 | 1.4 | 615,903 |
| Codex, no skill | 11 of 11 | 3 of 10 | 2.2 | 989,973 |

Paired by case, the skill made Claude faster in 20 of 21 cases (median 2.05x) and Codex faster in 18 of 21 (median 1.58x). Total tokens fell from 22.2M to 9.6M for Claude and from 22.1M to 13.8M for Codex.

- The one miss without the skill (P4, Claude): the agent ran a `rocketride` CLI that was not built from the checkout. It noticed the source would exit 0 while the installed CLI exited 1 and set the difference aside. With the skill, `rr-verify doctor` flags a wheel older than the SDK source.
- False alarms were reproduced by hand before being counted. Reports that turned out to be real bugs on develop are in `cases.json` as `known_issues` and are not counted as false alarms.

## Caveats

- One run per case per variant. Treat differences of one case as noise.
- The area prompt tells the agent where to look, and `prepare` builds `dist/` before the agent starts. Both make verification easier than real use, so the no-skill numbers are an upper bound on what an agent does unaided.
- Planted bugs are small and local. Replayed bugs are real fixes reverted onto current code, not the original buggy commits.
- A Docker engine (`rr-baseline-engine`, release 3.5.0.37) held port 5565 on the eval machine throughout. The skill avoids it; agents without the skill had to notice it.
